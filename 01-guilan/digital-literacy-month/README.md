# 贵兰在线 · 全民数字素养能力提升实践活动交互原型 V1.4

直接打开 **index.html**。无需安装依赖、启动构建或连接外部服务。请保留本文件夹结构后整体分享，不要只发送 index.html。

## 页面与文件

- `index.html`：首页活动 Banner 示例、原有数字素养区、新增活动专题作品区、OPC 模块示意。
- `gallery.html`：全部作品（标签与专题并行筛选、排序、搜索）和活动专题列表；第一期为五段位榜单。
- `detail.html`：五种类型作品的详情，视频／音频播放器、HTML 打开入口、图文／文档正文。
- `submit.html`：登录门槛、五类投稿表单、封面预览及正文内图文混排、提交反馈。
- `admin.html`：专区配置、作品审核、作品管理、标签、后台新增与编辑。
- `work.html`：独立 HTML 交互作品示例。
- `styles.css`、`data.js`、`app.js`、`admin.js`：共用样式、示例数据及交互逻辑。
- `assets/`：本地 SVG、视频及音频演示素材。
- `设计与状态.md`：范围、状态及实现边界。
- `验证/`：页面截图、检查记录及无依赖状态自检。

## 建议评审路径

1. 首页活动 Banner → 新增专区 → 切换三个活动专题 → 查看更多。
2. 游客查看详情及播放媒体，点赞时体验演示登录；已登录后可点赞或取消。
3. 在“提交作品”填写资料，先上传封面，再选择内容类型；图文直接在富文本编辑框中排版并通过工具栏插入图片。也可点击“原型体验：使用示例封面／文件”。
4. 顶部“管理端”→ 内容审核 → 检查作品 → 单件处理，或勾选待审核作品批量通过／填写统一理由批量不通过。
5. 作品管理 → 编辑标签、下架、重新发布；专区设置中可改名字、咨询信息、活动专题名称及顺序、首页展示开关、可选头图及默认底图。
6. 顶部“评审说明”可模拟下一次提交失败，验证内容保留及重试，也可恢复初始演示数据。

## 已确认的产品边界

本期包含视频、音频、单 HTML、图文、文档；文档和图文都按正文模式展示。文档解析、文件格式及图文编辑能力由用户与开发确认。本期不含“我的提交”。

采用每账号每作品一个有效赞、可取消，标签独立设置。排序、点赞细则是按讨论建议制作的可评审行为，可继续调整。

## 本地状态

HTTP 预览使用 localStorage 联动页面，同浏览器其他已打开页面可同步更新。直接文件模式使用 URL 片段快照传递数据，避免各 HTML 文件存储隔离；新标签页得到的是打开时的快照，不模拟生产数据库实时同步。快照只用于当前原型，勿填写真实个人资料或密钥。原型文件不包含实际用户数据。

文件选择仅在本地预览。保存作品名、简介、富文本正文（含图片）、文件名及封面缩略图，不上传或持久化视频、音频、HTML、文档的原始二进制。后续预览使用明确标注的示例素材，文档正文不代表真实解析结果。HTML 示例不会执行学生上传的代码。

正式开发需接入真实账号认证、文件存储、权限与审核服务、文档解析、独立 HTML 隔离托管；本原型不承担这些生产能力。
