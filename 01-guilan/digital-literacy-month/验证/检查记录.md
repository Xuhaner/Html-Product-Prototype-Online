## 限制与未验证项

- 浏览器工具不允许 file 协议直接打开。已验证 file 模式状态传递逻辑，但未完成浏览器 file 模式端到端实测；需要评审者直接打开 index.html 快速确认其浏览器策略。
- 已提供 prefers-reduced-motion 样式；浏览器工具未提供强制切换该系统偏好的能力，未实测强制减少动态模式。
- 图文／文档真实解析、服务器权限、登录、上传进度、存储服务异常与 HTML 隔离均为正式开发边界。
- 本地媒体为六秒演示文件；不代表真实学生作品内容。文档为示例正文，不对上传文件执行转换。
- 新开标签页在文件模式中为打开时的数据快照；正式多端实时协作不在原型范围。
