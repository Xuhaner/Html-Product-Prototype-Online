# V1.4 原型范围

模式：Prototype，可交互多文件 HTML。面向学生投稿、访客浏览及市场部审核人员。视觉依据为用户提供的贵兰在线首页、OPC 列表及后台截图：蓝白配色、横向高校标签、左侧分类、后台表格与抽屉。

页面：index.html 首页；gallery.html 专区列表；detail.html 作品详情；submit.html 投稿；admin.html 后台；work.html 单 HTML 示例作品。

状态：游客／演示登录；点赞／取消；活动专题、标签筛选与排序切换；无匹配内容；上传字段校验／提交中／可重试错误／提交成功；后台待审核／驳回／发布／下架；配置保存；移动端适配。用原生 dialog 处理登录、咨询、审核及编辑，支持 Escape 和焦点恢复。

本期包含视频、音频、单 HTML、图文、文档。图文和文档详情都按正文展示；文档解析、支持格式及图文编辑器的实际实现由用户与开发确认。本期无“我的提交”。

数据为本地虚构示例，账号为演示登录，不调用真实服务。HTTP 预览使用 localStorage 在同一浏览器内联动页面；直接文件模式通过 URL 片段快照传递状态，避免各 HTML 文件存储隔离。新标签页使用打开时的快照。上传文件只预览并保存名称，不上传，不持久化原始媒体、HTML 或文档二进制，仅保留封面及正文配图缩略图；审核预览的媒体及文档为本地演示素材。正式产品需接入认证、文件存储、审核权限、文档转换与 HTML 隔离托管。

模拟失败由顶部“评审说明”中的一次性开关触发，仅用于验证提交重试。未模拟网络加载和生产服务异常。原型设置与作品数据可在评审说明中重置。

所有素材、CSS、JS 均在本目录，不依赖构建或服务，直接打开 index.html。原型默认每账号每作品一赞、可取消，标签独立设置；这些按讨论建议制作，仍可在评审时调整。


V1.1 用户评审修订：卡片保留标题、作者、奖项、点赞，取消学校、时间、文件类型；列表无“全部作品”，默认首个分区；前后台封面在类型上方，图文正文改为内嵌图片的富文本。后台分区管理、可选头图／默认底图、直接下架、已发布与已下架的管理列表、待审核单选／多选／全选／部分选择／无可选、批量发布及统一理由不通过均纳入状态模型。批量审核保存失败需整批回滚，过期状态不可再次审核。


V1.2（2026-11-03）：专题分类改为“贵兰·AI实践月 · 第1／2／3期”；页面文字统一“活动专题”。标签保留原四类并加入五段位，全部使用不同颜色。第一期配置 20 件作品，按 8／6／3／2／1 分组，展示青铜至王者五个独立模块，王者视觉最强。比例仅用于本次示例，原型不推断生产环境段位评定规则；段位由标签手动设置。排序在各阶段内部生效；无段位作品仍显示于“其他作品”，避免发布后消失。第二、三期为普通列表。

后台表格拆分独立字段；配置中的活动咨询改为共用富文本，新增空内容校验、文字样式及图片保存和前台显示状态。原有详情返回及下架、批量审核逻辑继续保留。


V1.3（2026-11-03，来源：本轮用户修订）：审核列表移除点赞、标签；管理列表通过独立排序选择器提供点赞升降序。全部作品恢复并作为列表默认入口，包含所有已发布内容，标签与专题独立且可组合筛选；空态支持一键清空，详情返回保留条件。第一专题榜单王者优先，五段位内部按点赞倒序；移除说明、阶段副标题、比例和其他作品，王者也使用小卡。后台未分配段位的作品不进入榜单，可在全部作品查看。V1.1／V1.2 的相反描述保留为历史，该轮行为以 V1.3 为准，后续由 V1.4 补充。


## V1.4 当前版本（2026-11-04）

- 优秀作品标签与段位分别保存，可同时展示。首页／列表卡片在标题右侧、点赞上方展示“优秀作品”；手机窄卡片折到标题下一行靠右。详情页在段位旁展示“优秀作品”。未标记的作品不显示优秀标签。
- 管理端标签仅保留“无标签、优秀作品”，新增默认无标签；编辑标签不改变原有榜单段位。前台标签筛选保留优秀作品及五段位，可与专题筛选组合使用。
- 五种详情统一使用“作品展示”标题：视频播放器；HTML 封面＋说明＋打开按钮；音频封面＋标题／作者／专题＋播放器；图文正文及正文图片；文档浅灰底白纸正文。HTML 原额外标题／类型提示、音频英文眉题与底部说明、文档转换提示已移除，生产能力边界仍在评审说明与本文保留。
- 初始示例共 36 件：26 已发布、8 待审核、1 驳回、1 下架。6 件已发布作品带优秀标签；第一期 20 件榜单作品和五段位数量不变，优秀标签不参与段位判定。审核页仍无点赞／标签列，管理端点赞升降序保留。
- 专区设置保留名称、可留空的活动说明、头图及显示开关；活动咨询信息和专题管理各有独立按钮、弹窗及保存操作。弹窗保存不提交或丢失尚未保存的基础设置；取消不改动已保存内容。
- 专题管理支持新增、编辑名称、拖动／上移下移／排序值调整、删除空专题。所有状态的作品都计入删除检查；有作品时删除置灰。确认保存时再次检查，名称不可空白或重复，保存失败回滚并保留弹窗草稿。专题顺序同步首页、列表和投稿选项；已有第一期榜单模式保留，新专题使用普通列表。
- 存储键继续使用 `guilan-literacy-prototype-v1`，数据结构版本升为 `schemaVersion:3`。保留 `schools/school` 和 `award` 字段；新增 `tier` 保存段位，`award` 只保存空值或“优秀作品”。旧数据升级保留正文、作者、点赞、审核状态及专题配置，补齐待审核演示样例；旧一等奖／二等奖／三等奖按本次标签收敛移除。
- 仍为本地多文件原型，无真实认证、附件上传、文档解析或 HTML 生产托管；本期不含“我的提交”。直接文件模式已在本轮用隔离浏览器验证后台设置→首页→榜单→详情的状态传递，不代表所有浏览器环境都已覆盖。
