# 睿秀学城：校内基础教学首批需求与评审清单

版本：首批评审稿 0.2；日期：2026-11-05；状态：范围已确认，细则待评审。

来源：用户已确认先做校内基础教学，在线编程评测、同步互动课堂不进入首批，AI 相关尝试后置。本稿列出拟开发需求及验收目标，不把现有本地 Demo 视为正式系统。原完整版本与两份完整 PRD 保留。用户本轮补充：首页完整保留，个人中心只保留个人资料和教学相关栏目，“我的学习/课程”与课程教学功能完整带入；购买记录、积分成长继续后置。

## 1. 首批目标与边界

让教师能手工建设并发布课程，组织班级和学生；学生能进入课程学习、完成作业、测验与考试；教师能批阅并发布成绩，学生能查看结果。真实交付时，同一账号、课程、名册、提交及成绩必须在两端一致。

首批不含：AI 学习/学习包/智能建课/生题/生成视频/教学建议，在线编程与 SQL 执行评测、同步课堂与直播、数字竞技、收费交易与发票、付费专区运营、积分徽章排行榜、预测式学情预警及完整角色设计器。编程课程仍可教授代码，代码或报告以文件提交、人工批阅，不提供执行沙箱。

角色：学生、教师、平台管理员。机构仅作为学校归属与管理范围；跨机构开放招生和多租户运营另议。账号注册/导入方式、管理员初始授权方式待评审，不因 Demo 任意账号登录推定正式政策。

## 2. 需求清单

下表均属首批拟开发范围。“验收要点”是正式系统要求；第 5 节另列 Demo 可用于评审的程度。

| --- | --- | --- | --- |
| H01 | 首页/全角色 | 完整首页及两种风格、章节定位与课程入口 | 保留愿景、角色、教育矛盾、理念、在线学习、合作机构六部分；风格切换、移动端、减少动效及课程跳转可用；不以评审说明替代首页 |
| H02 | 机构展示/学生 | 首页机构链接、机构列表与关联课程 | 全部合作机构和单机构可打开；已有课程直达详情，其余资料预览，不虚构后台课库同步 |
| U05 | 安全/学生 | 手机邮箱绑定修改、密码、账号注销与撤回 | 验证码/密码校验、敏感值清理、注销确认和撤回状态明确；真实认证及注销政策另评 |
| C09 | 课程/双方 | 知识点展示、图谱定位与教师配置 | 查看、定位、高亮和重置；教师维护节点与关系，明确发布与学生端同步边界；不依赖 AI |
| C10 | 课程/双方 | 讨论、回复及教研团队 | 学生提问/回复，教师管理讨论与团队；显示状态和访问范围一致 |
| C11 | 课程/双方 | 完整课程成果与继续学习路径 | 总览、目录、作业测验、知识点、公告、讨论、团队、成果八类内容可走查；文件作业替代执行入口；证书样例不代表正式发证 |
| R06 | 复习/学生 | 错题搜索、题型筛选、详情与解析 | 按课程/来源回顾，答案公开遵循原测评规则；正式系统须定义收录/去重，不能用静态样本证明自动收录 |
| R07 | 收藏/学生 | 教学课程与任务收藏、筛选、取消及返回 | 收藏入口和个人中心使用同一记录；空态与取消反馈正确；编程题单收藏随后续实践版评审 |
| U01 | 账号/全角色 | 登录、退出、失效会话处理 | 无权限或失效会话不能访问受限内容；退出真实生效 |
| U02 | 账号/管理员 | 学生、教师、管理员资料与账号启停 | 唯一账号；必填、格式与重复校验；禁用后限制访问且保留历史 |
| U03 | 权限/管理员 | 分配教学负责人和基础管理范围 | 教师只看负责课程、班级、学生和提交；限制也覆盖详情、候选项与导出 |
| U04 | 资料/全角色 | 查看并修改允许编辑的个人资料 | 不可编辑的账号标识只读；修改有校验和保存反馈 |
| C01 | 课程/教师 | 课程列表、查询、创建与编辑 | 名称、类型、简介、封面、主讲/团队、状态与负责人可核对；不能创建重复标识 |
| C02 | 课程/教师 | 课程大纲、目标、教学安排 | 必填项、富文本及内容校验；保存后可继续编辑 |
| C03 | 备课/教师 | 教学模块、章节/课时、排序与显隐 | 增删改和顺序持久化；隐藏内容学生不可通过直达地址访问 |
| C04 | 资源/教师 | 手工配置视频、课件和下载附件 | 文件格式/大小/访问范围可配置；上传处理失败有反馈；被引用资源删除有规则 |
| C05 | 发布/教师 | 课程预览、发布与下架 | 草稿学生不可见；发布检查必要内容；下架及已加入学生的访问规则明确 |
| C06 | 发现/学生 | 浏览、搜索及按课程类型筛选 | 只展示学生有权看到的课程；公开/专属类型与资格说明一致 |
| C07 | 学习/学生 | 目录、课时、课件浏览与资料下载 | 返回目录定位正确；课时切换与下载权限准确；媒体不可用可重试 |
| C08 | 学习/学生 | 进度保存与继续学习 | 刷新、重开、重新登录后按正式账号恢复；完成条件不能由客户端伪造 |
| B01 | 班级/教师 | 新建、编辑、查询班级及课程关联 | 学期、课程、名称与负责人完整；班级变更不丢历史记录 |
| B02 | 名册/教师 | 添加、导入、移除学生及查看名单 | 导入预检、逐行错误与去重；有效成员更新人数；移除后资格按规则变化 |
| B03 | 团队/教师 | 管理班级协作教师 | 创建者/负责人权限明确，不能越权操作他人班级 |
| B04 | 入课/学生 | 专属课程申请与状态查看 | 待审核、已通过、已驳回与理由可见；待审核不自动授予学习资格 |
| B05 | 入课/教师 | 单条/批量通过及驳回 | 驳回理由必填、重复处理受限；处理结果回传学生并更新资格 |
| Q01 | 题库/教师 | 手工新增、编辑、预览选择与填空题 | 题干、选项、答案、解析、分值及归属有效；无答案不能发布 |
| Q02 | 题库/教师 | 搜索、分类、共享与批量导入 | 共享范围明确；CSV 模板与校验结果一致，错误项不静默入库 |
| Q03 | 测验/教师 | 手工组题及次数/限时/开放/答案规则 | 校验题目引用、总分和起止时间；已发布试卷变更有保护 |
| Q04 | 练习/学生 | 作答、反馈、解析与允许重做 | 按练习规则显示反馈；记录每次提交；不得覆盖考试的保密规则 |
| Q05 | 测验/学生 | 暂存、续答、交卷与成绩 | 次数与计时跨刷新正确；重复提交幂等；按规则取最高/最后成绩 |
| A01 | 作业/教师 | 配置要求、班级、附件、截止及评分 | 满分、格式、大小、迟交及重交规则明确；只向指定学生开放 |
| A02 | 作业/学生 | 查看要求、下载模板及提交文件 | 有上传进度、成功/失败；失败可重试且不虚报已提交；保存提交版本和时间 |
| A03 | 作业/学生 | 查看提交记录及按规则重交 | 明确以哪版作为批阅依据；截止后和已批阅后重交受规则限制 |
| A04 | 批阅/教师 | 未交/待批阅列表、附件查看、评分评语 | 教师收到真实学生提交；分数不超范围；草稿与已发布成绩分开 |
| A05 | 成绩/双方 | 发布作业成绩，学生看分数和反馈 | 同一提交的分数/评语一致；重发、撤回和统计更新可追溯 |
| E01 | 考试/教师 | 配置试卷、资格、时间、时长和次数 | 题目引用稳定，总分准确；开考前/结束后/无资格的访问行为明确 |
| E02 | 考试/学生 | 考试规则确认与进入 | 服务器校验资格与时间；错误原因可理解；前端状态开关不能绕过 |
| E03 | 考试/学生 | 作答、题号导航、暂存与中断恢复 | 多次刷新不重置倒计时或答案；保存失败提示，恢复到正确作答记录 |
| E04 | 考试/学生 | 手动/超时交卷及漏答确认 | 同一尝试只交一次；超时按已保存答案交卷；网络失败可确认最终提交状态 |
| E05 | 批阅/教师 | 客观题判分及需人工题目评分 | 自动与人工分数汇总一致；人工覆盖需留依据；不得使用模拟评测结果判代码 |
| E06 | 成绩/教师 | 发布/撤回成绩及控制答案公开 | 未发布学生只能看到待批阅；成绩、评语、答案按独立规则开放 |
| E07 | 成绩/学生 | 成绩与允许的作答回顾 | 只能查看本人记录；未公开试题/答案不从页面或接口泄露 |
| R01 | 个人中心/学生 | 我的学习、作业、测验与考试记录 | 来自实际账号行为，与课程页一致；区分未交、已交、待批阅与已发布 |
| R02 | 公告/教师 | 课程公告的发布、下架和阅读 | 正确课程范围可见；学生能查看最新安排及已读状态 |
| R03 | 通知/双方 | 入课结果和成绩发布等必要通知 | 点击进入对应记录；重复事件不重复通知；不含首批短信承诺 |
| R04 | 统计/教师 | 完成、提交、未交、成绩及 CSV 导出 | 使用同一名册和提交数据；分母、撤回及重交口径一致；导出受权限控制 |
| R05 | 追溯/管理员 | 关键发布、审核、批阅与账号操作记录 | 记录操作者、对象、时间和结果；纠错不无痕覆盖历史 |
| N01 | 数据/系统 | 服务端保存与跨端关联 | 课程、课时、成员、任务、试卷、尝试、提交和成绩有稳定标识；不能靠展示名匹配 |
| N02 | 文件/系统 | 文件存储与授权下载 | 文件实际可读取；文件名登记不算上传；删除与引用关系可处理 |
| N03 | 交互/全角色 | 校验、空态、失败恢复与基础适配 | 桌面/手机可操作，表单对齐、键盘焦点、敏感字段清理；错误不导致已存答案丢失 |

## 3. 关键状态与关联

- 课程：草稿 → 已发布 → 已下架；显示/隐藏资源另设访问控制，不能仅移除入口。
- 入课：未申请 → 待审核 → 已通过/已驳回；重申与撤权须有单独规则。
- 作业提交：未提交 → 上传中 → 已提交 → 待批阅 → 已批阅；上传失败不进入已提交。批阅与成绩发布分开，重交生成版本。
- 考试尝试：未开始 → 作答中 → 已交卷 → 待批阅 → 已批阅；成绩另有未发布/已发布/已撤回状态。
- 时间以北京时间展示，正式计时与开放限制由服务端决定；Demo 固定日期仅用于制造场景。
- 名册确定应交人数；有效提交确定实交人数；统计明确按学生还是提交版本计数。
- 试卷题目应保留发布/作答快照，后续改题不能改变学生既有成绩依据。

## 4. 评审必须定下来的规则

| 议题 | 建议起点，均待评审 | 影响 |
| --- | --- | --- |
| 账号来源 | 学校/管理员创建或导入，是否开放学生自注册待定 | U01–U03、B02 |
| 课程发布 | 校验必要资料与可学习内容；下架后历史记录保留 | C01–C11 |
| 班级与入课资格 | 明确班级导入是否直接授课、申请通过是否入班；移除与撤权分开 | B01–B05 |
| 学习完成条件 | 视频/课件/文件分别定义，不能只按打开页面认定完成 | C08、R04 |
| 文件作业 | 支持格式、大小、截止、迟交、最多重交次数及已批阅后处理 | A01–A05 |
| 测验取分 | 次数和最高/最后成绩按任务配置，不统一写死为两次 | Q03–Q05 |
| 考试恢复 | 次数、晚进场、截止/时长关系、断线和自动交卷策略 | E01–E04 |
| 成绩与答案 | 分开控制发布；改分/撤回后学生收到通知，保留依据 | A05、E05–E07 |
| 数据保留与导出 | 账号禁用、课程下架、成员移除后的历史访问及导出权限 | U02、R04–R05 |

首批范围确认不等于这些参数已确认，也不自动等于固定开发排期。

## 5. Demo 对照与缺口

独立入口为本目录上一级 `index.html`，15 个学生端 HTML、12 个后台 HTML。复用当前完整原型的基础教学页面与视觉；评审首页、课程列表、个人中心和管理工作台按本批收敛。

| 需求组 | Demo 可评审内容 | 尚需真实系统实现/补齐 |
| --- | --- | --- |
| U01–U05 | 登录、角色切换、账号列表与完整资料/安全表单 | 真实认证、有效权限及账号跨页联动 |
| C01–C11 | 手工课程资料、备课模块与资源、目录、课件/视频状态和进度 | 资源上传播放、正式发布、课程版本与跨端可见性 |
| B01–B05 | 班级列表、名册、申请及通过/驳回页面 | 实际导入、待审回传、成员与课程资格统一；学生申请仍自动模拟通过 |
| Q01–Q05 | 选择/填空题库及 CSV、手工测验配置、练习/小测答题与结果 | 题库配置驱动学生试卷、正式计时与作答存储 |
| A01–A05 | 文件作业要求/选择/提交，教师报表与人工评分 | 文件只登记当前页元数据；学生提交不进入教师页；评分不回传 |
| E01–E07 | 规则、环境检查、答题/续答/交卷、教师评分与发布 | 两端使用独立样例；正式资格、服务器计时、真实成绩回传 |
| R01–R07 | 我的学习/作业/考试、错题与收藏、课程公告、报表与导出 | 业务事件通知、统一统计、完整审计链；未提供所有生产异常流程 |
| N01–N03 | 无构建、直接双击、桌面/手机界面 | 无服务端、数据库或对象存储；本地状态不能替代账号数据 |

Demo 中保留题量、分数、课程名和日期作为样本；不增加真实直播、评测、AI 或支付。后台课程资料/备课保存到本标签页，其他多数后台修改刷新恢复；学生普通学习记录同标签页保留，文件作业刷新丢失。Demo 用来讨论流程，正式验收按第 2 节标准。
