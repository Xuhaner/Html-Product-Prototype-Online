课程大纲

本课程从程序设计与计算思维出发，介绍 Python 基础语法、数据类型、流程控制、函数、文件操作与简单项目实践。

一、课程目标

  1. 理解程序设计的基本思想，掌握 Python 的基础语法与常用数据类型。
  2. 能够运用条件、循环、函数和组合数据类型设计解决方案。
  3. 具备阅读、调试和改进简单程序的能力，并能完成小型综合编程任务。

二、教学内容、学时分配和作业要求

第一章 初识 Python（6 学时）

  • 1.1 程序与计算思维
  • 1.2 Python 开发环境
  • 1.3 第一个 Python 程序

第二章 基础语法（6 学时）

  • 2.1 变量、常量与表达式
  • 2.2 数字、字符串与布尔值
  • 2.3 基本输入输出
  • 2.4 变量与类型实战 · 视频与数字竞技
  • 2.5 表达式与输入输出挑战 · 视频与数字竞技

第三章 流程控制（8 学时）

  • 3.1 条件判断
  • 3.2 for 循环与列表遍历
  • 3.3 while 循环与嵌套结构

第四章 函数与模块（8 学时）

  • 4.1 函数定义与调用
  • 4.2 参数、返回值与作用域
  • 4.3 模块与标准库

第五章 组合数据类型（8 学时）

  • 5.1 列表与元组
  • 5.2 字典与集合
  • 5.3 常见数据处理

第六章 文件与项目实践（6 学时）

  • 6.1 文件读写与异常处理
  • 6.2 程序调试与测试
  • 6.3 综合编程任务
