# 睿秀学城 · 校内基础教学评审版

双击 [index.html](index.html) 打开，无构建、无服务器、无安装要求。此目录是从当前完整 `resole-study/` 独立提取的评审副本，可以整体复制发送。

- [学生课程](pages/courses/courses.html)：Python 程序设计、数字素养与安全两个教学样本，覆盖公开/专属访问场景；详情保留课程八类教学内容。
- [教师工作台](admin-prototype/index.html?role=teacher)：手工课程/备课、班级名册、入课审核、选择/填空题库、作业与考试。
- [平台管理](admin-prototype/super-admin.html?role=super)：基础账号及相同教学管理入口。
- [首批需求与评审清单（可离线阅读）](pages/home/review-requirements.html)；[Markdown 源文档](docs/首批需求与评审清单.md)：需求编号、验收、待定规则和 Demo 缺口对照。

首页恢复完整理念内容、两种风格与合作机构。通过“原型状态 → 基础教学评审说明”或 [评审说明页](pages/home/review-guide.html) 查看 T00–T07 路线与后续版本规划，再走查：手工建课 → 班级/资格 → 学习与作业 → 练习/测验 → 考试 → 教师批阅发布 → 学生回看/教师导出。后台批阅使用独立示例，不能演示学生提交实时进入后台。

学生端桌面主导航和手机底栏均只保留“首页、课程”；“我的学习”通过右上角头像菜单进入，不设独立导航标签。个人中心保留我的学习/作业/考试/错题/教学收藏、完整个人资料及账号安全，保留筛选、查看详情、取消收藏与返回课程；购买记录和积分成长不进入首批。

本批不展示 AI、在线编程评测、同步互动课堂、收费交易、积分徽章排行榜、数字竞技与复杂运营。代码仍可作为课程教材或提交文件，不执行代码。完整原型保留在外层相邻的 `resole-study/`，本版不链接回完整版本，以免误入后续范围。

## 原型边界

学生普通学习与测评用 `ruixiu-basic-v1:` 和当前根目录作用域保存在同标签页 `window.name`；换标签页、关闭或切换版本不保证保留。文件作业只保留当前学习页的文件元数据，不上传，刷新丢失。后台课程与备课使用 `ruixiu-basic-admin-courses-v1:` 加当前目录及角色的 `sessionStorage`；其他后台多数操作只在当前页演示、刷新恢复。未连接真实账号、权限、媒体、通知、数据库或文件服务。账号登录使用演示规则，后台默认可直接访问。

学生申请专属课程后仍自动模拟通过；后台审核与学生端独立。正式需求要求待审/通过/驳回真实回传。学生交卷后待批阅，后台评分发布也不会回传。真实交付按需求清单验收，不把当前 Demo 的模拟成功提示当作闭环。

## 目录与验证

学生端仅根首页，业务页位于 `pages/courses`、`pages/tasks`、`pages/profile`、`pages/institutions` 和 `pages/home`，使用 `<base href="../../">`。后台独立位于 `admin-prototype/`，两端 CSS/JS 不交叉引用，沿用 shared/data/pages 分层。评审首页样式位于 `css/modules/review.css`，从共享样式入口导入。

`tests/review.cjs` 验证本评审版的保留页面、资源、按钮路由和首批入口；`tests/flows.cjs` 验证代表流程；`tests/home-profile.cjs` 仅检查恢复的首页、个人资料/安全、教学栏目与课程知识点，使用独立无头 Playwright Chromium。验证依赖是开发工具，原型本身不依赖它；有 Playwright 时从本目录运行 `node tests/review.cjs` 与 `node tests/flows.cjs`。当前验证结果与限制记录于外层 MEMORY；不沿用完整版本的历史通过证据。
