# 基础教学评审版 · 管理端

教师打开 [index.html](index.html?role=teacher)，平台管理员打开 [super-admin.html](super-admin.html?role=super)。原型默认已登录，头像退出可演示登录；不代表真实认证与权限。

保留课程列表与手工备课、课程知识点/图谱、班级/名册、专属入课审核、作业/考试列表及批阅、选择题/填空题库、个人资料和平台账号管理。资源在所属课程的备课工作区手工配置，无独立 AI 视频生成或智能建课。账号机构仅作为资料归属，复杂机构管理与完整角色设计器后置。

课程资料与已保存备课在当前标签页按角色保存，其他多数编辑、审核和评分刷新恢复。与学生端独立，不接收学生提交或回传评分；班级 Excel 只登记文件名，不导入学生。正式系统所需能力见 [首批需求清单](../docs/首批需求与评审清单.md) 和 [使用说明](../README.md)。
